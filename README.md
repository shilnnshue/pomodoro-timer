## ✨ 功能特点

- ⏱️ **经典番茄钟**：默认 25 分钟工作 + 5 分钟休息
- 🎛️ **可自定义时间**：工作时长、休息时长均可调整
- 📊 **完成计数**：实时显示已完成的番茄数量
- 🎨 **简洁界面**：清爽设计，专注当下
- 📱 **本地运行**：纯前端，无需安装、无需联网

---

## 🚀 快速使用

1. 克隆或下载本仓库
2. 用浏览器直接打开 `index.html`
3. 点击「开始」即可开始专注！

```bash
git clone https://github.com/shilnnshue/pomodoro-timer.git
cd pomodoro-timer
# 双击 index.html 或用本地服务器打开
```
